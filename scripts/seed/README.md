# Store seed (dummy catalogue + data model)

Creates in Shopify (via the Admin API):

- **Product metafields** (`custom.*`, readable by the storefront): `bespoke`, `size_type`
  (`made_to_measure` | `preset` | `one_size`), `composition` (JSON list of parts → fibre %),
  `care_instructions`, `measurement_fields` (keys for the made-to-measure questionnaire),
  `production_time`, `edition`.
- **`product_feed` metaobject** (handle `main`): header, description, featured products, collections.
  Edit it in Shopify admin → Content → Metaobjects.
- **Products** with variants (Size/Length + Color), stock levels, and internal customs data on each
  variant's inventory item: HS code, weight, SKU (+ country of origin if `COUNTRY_OF_ORIGIN` is set).
- **Collections**, all published to the Hydrogen storefront (`terribelle-storefront` publication).

Data lives in `catalog.mjs`. Placeholder images are generated by `generate-plates.mjs`.

```bash
npx shopify store auth --store terribelle-ev5cs4ik.myshopify.com \
  --scopes read_products,write_products,read_metaobject_definitions,write_metaobject_definitions,read_metaobjects,write_metaobjects,read_publications,write_publications,read_files,write_files,read_inventory,write_inventory,read_locations
npm run seed:images
COUNTRY_OF_ORIGIN=FR npm run seed   # country code optional
```

Existing items (matched by handle/key) are skipped, so re-running is safe.
